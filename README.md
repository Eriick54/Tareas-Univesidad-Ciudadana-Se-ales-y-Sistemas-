# Diseño e Implementación de Filtros Digitales

## Descripción

Este proyecto implementa filtros digitales pasa bajos, pasa altos y pasa bandas utilizando Python y la librería SciPy.

## Objetivos

- Diseñar filtros digitales.
- Analizar la respuesta en frecuencia.
- Aplicar filtrado a señales contaminadas con ruido.
- Comparar señales antes y después del proceso de filtrado.

## Herramientas utilizadas

- Python
- NumPy
- SciPy
- Matplotlib

## Filtros implementados

1. Filtro Pasa Bajos
2. Filtro Pasa Altos
3. Filtro Pasa Bandas

## Resultados

Las simulaciones muestran que cada filtro permite seleccionar determinadas componentes frecuenciales de la señal mientras atenúa las no deseadas.
